# PRD-003 实施任务清单

- 依据：`PRD-003-notification-lifecycle.md`
- 状态：M0 已锁定，M1–M8 已实现，M7 待手工验收
- 日期：2026-11-21

## M0 决策锁定

- [x] 铃铛只由非即时通讯的 Windows 通知点亮；邮件、即时通讯、AI 不点亮；点击始终进 Windows 通知页。
- [x] 紧凑模式保留岛上歌词；浏览器避让仍为细线且不显示歌词。邮件 / 即时通讯到达时正常弹横幅，结束后回到紧凑状态，不另设提示点。
- [x] AI 等待 / 问答直接展开详情；`auto_expand` 只影响横幅结束后的列表打开。
- [x] AI 完成 / 失败 / 中断 / 可能已中断先出横幅；`auto_expand` 在横幅结束后打开 AI 列表。
- [x] 事件容器里的电量只读 + tooltip。
- [x] 页面徽标与事件容器只统一模型、术语和时序，暂不合并模块。
- [x] `提醒方式` 改名「系统提醒」；AI 提示音跟随提醒总开关和声音开关，状态灯隐藏时不播放。
- [x] 行为页新增「岛体组件」入口；原「通知」组改名「横幅提醒」。
- [x] 横幅不持久化；持久化交给常驻图标或页面。

## M1 铃铛收窄

- [x] `receive_notification_from` 只为非即时通讯的 Windows 通知点亮铃铛。
- [x] 邮件、即时通讯提醒不再点亮铃铛。
- [x] 铃铛点击只进 Windows 通知页，删除邮箱页兜底。
- [x] Windows 通知横幅新增「查看」按钮，直接进入 Windows 通知页。
- [x] 清理邮件 / 即时通讯关闭时对铃铛窗口的复位。
- [x] 更新邮件设置说明和相关测试。

## M2 AI 状态灯与提示音

- [x] 收起态状态灯可直接点击进 AI 页。
- [x] 侧边停靠状态灯可点击进 AI 页。
- [x] AI 提示音受提醒总开关、声音开关和状态灯显示共同控制。
- [x] 等待中的详情不再依赖 `auto_expand` 保持展开。

## M3 岛体图标统一

- [x] 事件图标在横幅结束后开始计时。
- [x] 邮件、健康、待办、日程放进事件容器时持续到条件解除。
- [x] 新邮件在服务器已读状态未同步前按未读计入邮箱徽标，同步后以服务器状态为准。
- [x] 会议图标保留到会议开始，不再使用 10 秒默认值。
- [x] 事件容器里的专注、音乐可点击；电量只读 + tooltip。
- [x] 更新事件容器注释和相关测试。

## M4 AI 提醒呈现

- [x] 等待 / 问答直接展开详情，不先出横幅。
- [x] 完成 / 失败 / 中断 / 闲置先出横幅，按钮「查看」进入 AI 列表。
- [x] `auto_expand` 只影响横幅结束后的列表打开。
- [x] 提醒事件分为展开提醒（用户选择、审批）与横幅提醒（完成、中断、失败、闲置）。
- [x] 更新 AI 设置说明和相关测试。

## M5 提醒方式门控

- [x] `提醒方式` 改名「系统提醒」。
- [x] 增加适用范围说明：只影响岛仔自己的系统提醒；即时通讯、Windows 通知不跟随；AI 提示音跟随声音开关。
- [x] 核对 `Cmd::Notify` 只对 `system=true` 的内部提醒发出。

## M6 行为页信息架构

- [x] 保持「横幅停留」在横幅组，不迁移到展开组。

## M8 展开态常驻状态行

- [x] 展开后顶部保留与收起态相同的状态行，铃铛、天气、音乐、额度、AI 状态灯和事件容器保持可见可点。
- [x] 展开态时间只显示 `HH:MM`，不受 12 小时制、时段文字和秒数设置影响。
- [x] 「岛上显示 → 时间」开关只隐藏收起态时钟，展开顶栏仍显示时间。
- [x] 展开态不再重复绘制日期、电池、音乐和勿扰入口。
- [x] 状态行槽宽：简单图标 20（图形 14，四周留白约 3），AI 状态灯 14（圆点 9、闲置圆环外径约 10、等待光晕 16），邮箱 / 待办含数量 30，宠物 20；时钟、天气、额度、专注按内容。组件间距 8、两端内边距 10、容器间距 8。
- [x] 页面内容整体上移 6 点，页头更靠近顶部状态行；AI 会话列表首行与邮箱列表对齐。
- [x] 展开面板整体加高一个状态行，页面内容下移，分页圆点和拖动把手同步下移。
- [x] 侧边停靠展开后同样显示顶部状态行。
- [x] 展开态设置与勿扰固定在状态行最右侧；勿扰开关开启时无论是否激活都常驻，页面标题行不再重复放置。
- [x] 状态行简单图标统一为 14 点视觉尺寸：电池、音乐、铃铛、邮箱、健康、待办、置物架、日程同步调整；勿扰月亮与设置齿轮同用 20 点外框、14 点图形；时钟、天气、额度、专注和吉祥物保持各自的数据布局。
- [x] 展开态空间不足时先压缩组件间距，压到 4 点仍放不下才整体等比缩小，避免常驻图标在收起和展开态之间改变尺寸。
- [x] 岛外未读胶囊的 IM 图标按约 20 点视觉外框统一（微信 0.95、QQ 1.05、办公类 1.0），收起态统一为 0.85 倍。
- [x] 更新布局、页面徽标、事件容器和面板高度相关测试。
- [ ] 手工验收展开态图标可见性、时间格式和两端边距。
