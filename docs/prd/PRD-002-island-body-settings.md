# 岛仔 PRD：设置信息架构调整（岛体、行为、提醒与功能页拆分）

- 编号：PRD-002
- 状态：已实现，待手工验收
- 日期：2026-11-19（初稿）/ 2026-11-20（结构调整后定稿）
- 适用版本：岛仔 v0.6.66 之后
- 变更类型：设置页信息架构调整，默认行为不变；新增三项时长/动效设置
- 硬约束：不改现有 `settings.txt` 键名与默认值、不改现有控件行为；新增三个时长/动效键，默认值等于当前硬编码值；旧分页序号 0–15 仍可跳转，13、10 归一化到「岛体」，新页使用 16（岛体）与 17（剪贴板）
- 第 14 节记录 2026-11-20 第二轮调整，覆盖前文对应描述。

## 0. 调研结论

上一轮关于吉祥物、消息提醒和设置现状的结论继续成立：

- 吉祥物不是只跟音乐交互，但它和 AI 会话没有专属互动。本次不新增吉祥物与 AI 的联动。
- 聊天消息到达时，岛会展开为约 4.5 秒的通知横幅并自动收起，不会自动打开完整面板。
- 微信、企业微信、飞书、钉钉走任务栏闪动，不读取联系人和聊天正文。
- QQ 与其他 Windows 通知在开启「显示通知正文」后才显示 toast 文本；联系人可能作为正文的一部分出现，但代码不单独解析联系人字段。

本次新增的结论：

- 「岛体」相关设置原先分散在「通用」「外观」「页面管理」三个页面，用户需要来回找。这不是行为缺失，而是信息架构问题。
- 页面职责按四层划分：**通用管基础设置，岛体管岛上排布，行为管岛体行为，提醒管消息行为**。功能分组只保留各模块自己的领域设置。
- 「外观」的皮肤、背景模糊、形状、大小本质上也是岛体外观，并入「岛体」的「岛体外观」分组，不再单独成页。
- 「功能页面」是展开后的导航排布，属于岛体，并入「岛体」。
- 展开与收起、自动避让、全屏时隐藏、OLED 像素偏移都是岛体行为，归「行为」页（原「位置」页更名）；极简刘海是手动版的自动避让，移除。
- AI 会话的提醒事件开关和提示音本质是 Hook 事件配置，应留在「AI 会话」功能页；「提醒」页只保留跨来源的提醒策略（自动展开、重复提醒）。
- 「提示音」总开关与各事件开关重复，移除总开关，只保留按事件选择。
- 专注与健康、待办与置物原先合并在一个设置页，实际是两个功能模块，拆开；剪贴板是置物架的一部分，但配置独立，单独成页。
- 展开/折叠相关时长原本全部硬编码：消息横幅 4.5 秒、强制展开 4.0 秒；展开/收起动画由弹簧参数决定，没有绝对时长。本次将这三项开放为设置。

## 1. 背景与问题

调整前设置侧栏的「岛仔」分组包含「通用」「外观」「位置」「页面管理」，与岛体相关的设置被拆成三块：

| 调整前位置 | 设置内容 | 用户理解成本 |
|---|---|---|
| 通用 → 自动避让 | 岛被其他应用遮挡时是否收成细线、常用浏览器、自定义应用 | 被放在应用级「通用」页，和启动、时间格式混在一起 |
| 外观 → 岛体显示 | 极简刘海、岛仔吉祥物、OLED 像素偏移 | 和皮肤、形状、大小混在一起，但前者是行为，后者是外观 |
| 页面管理 → 岛上显示 | 收起时常驻组件的排序与开关 | 和功能页面开关混在一起，但前者是岛体内容，后者是导航 |

另外，「消息提醒」把跨来源提醒策略与 AI 会话的 Hook 事件开关混在一起；「页面管理」同时承担功能页导航和常驻组件，职责不纯。

结果是：

- 用户想调整「岛体怎么显示、显示什么、什么时候避让」时，没有单一入口。
- 「外观」同时承担视觉样式和显示行为，职责不纯。
- 「页面管理」同时承担功能页开关和常驻组件开关，职责不纯。
- 「通用」承担了自动避让这类岛体行为，和通用设置不在同一层级。
- 「提醒」页里塞入了 Hook 事件与提示音，和「AI 会话」功能页重复。

## 2. 目标与非目标

### 2.1 目标

1. 新增设置页「岛体」（序号 16），作为岛上排布的唯一入口：岛体外观、岛上显示、功能页面。
2. 「外观」（序号 13）并入「岛体」：皮肤、背景模糊、形状、大小迁入「岛体外观」分组，旧序号 13 仍打开该页。
3. 「功能页面」（序号 10）并入「岛体」：功能页开关与顺序迁入「岛体」页，旧序号 10 仍打开该页。
4. 「位置」（序号 14）更名为「行为」，并吸收岛体行为项：
   - 位置：显示屏、停靠、偏移（原有内容）。
   - 展开与收起：动画速度、展开后停留、OLED 像素偏移。
   - 避让：全屏时隐藏、顶栏适配、自动避让（含常用浏览器与自定义应用），同一张卡片。
5. 「通用」只保留基础设置：设置页外观、时间格式、启动、高级（兼容渲染）。「高级」改为与「启动」同级的普通分组标题，子项不再折叠。
6. 「消息提醒」（序号 6）更名为「提醒」，归入「应用」分组，定位为跨来源提醒策略页：提醒方式（含横幅停留）、系统状态、即时通讯、AI 会话消息、外部消息（仅自动展开与重复提醒见 AI 会话消息）。
7. AI 会话的提醒事件开关与提示音迁入「AI 会话」页（序号 15），分为「提醒事件」「提示音」两组；移除冗余的提示音总开关。提醒事件按呈现方式分为「展开提醒」（用户选择、审批）与「横幅提醒」（完成、中断、失败、闲置）两个子组。
8. 提醒事件重新命名与拆分：等待确认/回答拆为「用户选择」和「审批」；完成/中断拆为「完成」和「中断」；可能中断 → 「闲置」。
9. 「专注与健康」拆为「专注」（序号 2）与「健康」（序号 3）。
10. 「待办与置物」拆为「待办」（序号 4）、「置物架」（序号 5）、「剪贴板」（新页序号 17）。
11. 「剪贴板」使用新增的独立图标 `clipboard.svg`，与置物架区分。
12. 在「行为 → 展开与收起」开放动画速度（慢/标准/快）与展开后停留（默认 4 秒）。
13. 在「提醒 → 提醒方式」开放横幅停留（默认 4.5 秒）。

### 2.2 非目标

- 不改变任何运行时默认行为；新增设置的默认值等于当前硬编码值。
- 不改变现有配置键名与含义；AI 通知配置新增 `interrupted`、`question`、`approval` 键，旧 `waiting` 键只读迁移、不再写回。
- 不重排旧分页序号，不改变功能页到设置页的映射。
- 不把音乐、邮件、AI 额度、天气等功能模块的领域设置并入提醒页。
- 不把健康、邮件、日程提醒纳入提醒页。
- 不新增吉祥物与 AI 会话的互动。
- 聊天消息不自动展开完整面板，保持只显示横幅。
- 旧页不显示「已移至岛体」提示。
- 悬停意图（0.20/0.40 秒）与离开延迟（0.12 秒）不开放。

## 3. 术语与页面职责

| 页面 | 负责 | 不负责 |
|---|---|---|
| 通用 | 设置页主题、时间格式、开机启动、兼容渲染 | 岛体外观、岛上显示、行为 |
| 岛体 | 岛体外观（皮肤/模糊/形状/大小）、岛上显示（吉祥物、常驻组件与开关）、功能页面（开关与顺序） | 位置、展开收起、避让、提醒策略 |
| 行为 | 位置（屏幕/停靠/偏移）、展开与收起（速度/停留/OLED）、避让（全屏隐藏/顶栏适配/自动避让） | 岛体外观、常驻内容、提醒策略 |
| 提醒 | 各类消息/事件的提醒策略：提醒方式（含横幅停留）、系统状态、即时通讯、AI 会话消息（自动展开、重复提醒）、外部消息 | Hook 事件开关、提示音种类、各功能模块领域设置 |
| AI 会话 | 接入 AI 工具、显示、提醒事件（展开提醒：用户选择/审批；横幅提醒：完成/中断/失败/闲置）、提示音（哪些事件发声）、会话与审批 | 提醒方式、横幅停留、重复提醒 |
| 专注 / 健康 / 待办 / 置物架 / 剪贴板 / 邮箱 / 日程 / AI 额度 / 天气 | 各功能模块自己的领域设置 | 岛体、提醒、页面导航 |

定位一句话：

- 「岛体」：岛长什么样、收起时显示什么、展开后有哪些页面。
- 「行为」：岛怎么动、在屏幕哪里、遇到其他窗口怎么让。
- 「提醒」：消息/事件触发时怎么提醒、提醒到什么程度。
- 「AI 会话」：哪些 Hook 事件提醒、哪些事件发声。

## 4. 目标信息架构

### 4.1 侧栏结构

```text
应用
  通用        0
  岛体        16   ← 新增；吸收原「外观」13 与原「功能页面」10
  行为        14   ← 原「位置」更名，吸收展开与收起、避让
  提醒        6    ← 原「消息提醒」更名，从功能分组移入

功能
  音乐        1
  专注        2    ← 原「专注与健康」拆出
  健康        3    ← 原「专注与健康」拆出
  待办        4    ← 原「待办与置物」拆出
  置物架      5    ← 原「待办与置物」拆出
  剪贴板      17   ← 新增
  邮箱        7
  日程        8
  AI 额度     11
  AI 会话     15
  天气        12

其他
  关于        9
```

分组标题由 `SETTINGS_SECTIONS` 单独维护（标题 + 该组在 `SETTINGS_GROUPS` 中的起止下标），页面行不再各自携带分组名。第一组用「应用」而不是「岛仔」：它和「功能」构成「应用级设置 / 功能模块设置」的对照，也避免与窗口标题重复。

侧栏共 16 项。旧序号 13（外观）、10（功能页面）通过归一化映射到 16（岛体），侧栏选中状态与页面标题都显示「岛体」。

放置理由：

- 「通用」是应用级设置，「岛体」是岛体排布，「行为」是岛体动作，层级从静到动。
- 「提醒」是跨来源的事件策略，放在「应用」分组，因为它控制岛体在消息触发时的表现，而不是某个功能模块的设置。
- 「功能」分组只保留各模块自己的领域设置。

### 4.2 岛体页结构

页面标题：`岛体`

页面顶部说明：

> 岛体的外观、常驻内容与功能页排布。行为相关设置在「行为」。

内容顺序：

1. **岛体外观**：皮肤、背景模糊（仅毛玻璃皮肤）、形状、大小与「恢复默认」。
2. **岛上显示**：岛仔吉祥物、常驻组件拖动排序与「恢复默认」，以及时间、电量、天气、AI 额度、AI 会话开关。
3. **功能页面**：功能页开关与拖动排序，每行右侧「设置 ›」，底部「至少保留一个页面」提示。

线框示意：

```text

│ 岛体的外观、常驻内容与功能页排布。         │
│ 行为相关设置在「行为」。                   │
│                                            │
│ 岛体外观                                   │
│ ┌────────────────────────────────────────┐ │
│ │ 皮肤        经典 / 奶油 / 毛玻璃 …     │ │
│ │ 背景模糊                         [开] │ │
│ │ 形状              胶囊 / 圆角 / …      │ │
│ │ 大小            ───●───  100% 恢复默认 │ │
│ └────────────────────────────────────────┘ │
│                                            │
│ 岛上显示                                   │
│ ┌────────────────────────────────────────┐ │
│ │ 岛仔吉祥物                       [开] │ │
│ │ [岛体预览：拖动图标左右排序]  恢复默认 │ │
```

边界：

- 「岛仔吉祥物」与自动避让互不影响；被浏览器遮挡收成细线时吉祥物暂时隐藏，离开后恢复。
- 常驻组件预览继续跟随当前皮肤、形状、天气和电量状态。

### 4.3 行为页结构

页面标题：`行为`

内容顺序：

1. **位置**：显示屏、停靠（顶部/左右）、水平或上下位置、恢复居中。
2. **展开与收起**：动画速度（慢/标准/快）、展开后停留、OLED 像素偏移。
3. **避让**：同一张卡片内依次为全屏时隐藏、顶栏适配（显示方式：避开顶栏/岛仔置顶）、自动避让（总开关、常用浏览器、自定义应用与添加弹窗）。

线框示意：

```text
│                                            │
│ 位置                                       │

│ │ 停靠        顶部 / 左侧 / 右侧         │ │
│ │ 水平位置      ← ───●─── →  恢复居中    │ │

│                                            │
│ 展开与收起                                 │
│ ┌────────────────────────────────────────┐ │
│ │ 动画速度        慢 / 标准 / 快         │ │
│ │ 展开后停留              4 秒  [−] [+]  │ │
│ │ OLED 像素偏移                    [关] │ │
│ └────────────────────────────────────────┘ │
│                                            │
│ 避让                                       │
│ ┌────────────────────────────────────────┐ │
│ │ 全屏时隐藏                       [开] │ │
```

### 4.4 提醒页结构

页面标题：`提醒`

页面顶部说明：

> 消息或事件触发时，岛怎么提醒。

内容顺序：

1. **提醒方式**：提醒总开关、提醒方式（仅岛上 / 加系统通知 / 系统通知 + 声音）、横幅停留。
2. **系统状态**：音量、电源、网络、键盘、蓝牙设备，五项独立开关，无说明文字。
3. **即时通讯**：微信（含托盘一键唤起）、企业微信、飞书、钉钉、QQ，每行一个开关，开关左侧显示「监听中 / 未监听」状态胶囊。
4. **AI 会话消息**：自动展开、重复提醒，并提示「哪些事件提醒、提示音种类在『AI 会话』页设置」。
5. **外部消息**：Windows 通知监听状态与连接/断开、显示通知正文、除上述客户端外已开启通知的应用（只读展示），以及「打开 Windows 通知设置」按钮。

「AI 会话消息」在 AI 会话功能关闭时整体置灰，并显示关闭提示。即时通讯的监听状态来自实际监听器；开关打开但客户端未运行或权限失败时仍显示「未监听」。

### 4.5 AI 会话页结构（补充）

页面标题：`AI 会话`，内容顺序：

1. **接入 AI 工具**：各 Agent 的监控/审批开关、安装/移除/修复、重新扫描、清理旧 Hook。
2. **显示**：会话标题、列表行数、最近消息行数、会话记录保留。
3. **提醒事件**：展开提醒（用户选择、审批）与横幅提醒（完成、中断、失败、闲置；闲置指运行中超过 10 分钟没有事件）。
4. **提示音**：开始、提交、审批、完成、错误；无总开关。

### 4.6 功能页拆分

| 页面 | 内容 |
|---|---|
| 专注（2） | 专注时长、休息时长 |
| 健康（3） | 喝水提醒（间隔/每次记录/每日目标）、久坐提醒（时长）、提醒时段、午休不提醒 |
| 待办（4） | 仅功能页开关卡片，无额外设置 |
| 置物架（5） | 功能页开关卡片 + 当前条目数与「移除不删除原文件」说明 |
| 剪贴板（17） | 记录剪贴板开关、保存条数说明、打开剪贴板按钮；置物架模块关闭时置灰并提示 |

剪贴板页顶部说明：

> 在置物架的「剪贴板」分栏里查看最近复制的文字。

## 5. 迁移映射

### 5.1 通用 → 岛体 / 行为

| 内容 | 原位置 | 新位置 |
|---|---|---|
| 自动避让总开关、常用浏览器、自定义应用、添加弹窗 | 通用 | 行为 → 避让（自动避让卡片） |
| 全屏时隐藏 | 通用 → 启动 | 行为 → 避让 |
| 兼容渲染 | 通用 → 高级（折叠） | 通用 → 高级（同级标签，不折叠） |

原「通用」页保留：设置页外观、时间格式、启动（开机启动）、高级（兼容渲染）。

### 5.2 外观 → 岛体

- 「岛体外观」整组迁入岛体：皮肤、背景模糊、形状、大小、恢复默认。

### 5.6 AI 会话提醒 → AI 会话（事件 Hook）

| 旧控件 | 新位置与文案 |

| 失败 | 横幅提醒 →「失败」（不变） |

| 自动展开、重复提醒 | 保留在提醒 → AI 会话消息 |

### 5.8 新增时长与动效设置

这三项不是页面迁移，而是把现有硬编码值开放为设置。默认值等于当前值，升级后行为不变。

| 设置 | 当前硬编码 | 新键 | 默认 | 范围 | 位置 | 生效范围 |
|---|---|---|---|---|---|---|
| 横幅停留 | 4.5 秒 | `notice_hold_secs` | 4.5 | 1–15 秒，步进 0.5 | 提醒 → 提醒方式 | 聊天软件与 Windows 通知横幅 |
| 展开后停留 | 4.0 秒 | `page_hold_secs` | 4.0 | 1–15 秒，步进 0.5 | 行为 → 展开与收起 | 打开功能页、展开未读胶囊 |
| 动画速度 | 弹簧常量 | `motion_speed` | `normal` | `slow` / `normal` / `fast` | 行为 → 展开与收起 | 岛体展开、收起、悬停胀大 |

边界：

- 「横幅停留」只替换聊天与外部通知的 4.5 秒；AI 会话消息（等待 6 秒、其余 3 秒）和系统状态 HUD（2.5/8/12 秒）保持事件语义时长，不跟随本设置。
- 「动画速度」保留弹簧驱动，不改成绝对时长；速度倍率为 0.7/1.0/1.4，刚度按倍率平方缩放，阻尼比不变。只作用于 `OPEN_W`、`OPEN_H`、`CLOSE`、`SWELL_K` 及使用同一参数的通知宽度弹簧；拖拽、流体、宠物等其它动画不受影响。
- 岛体动画不受 Windows「显示动画」设置影响，始终按本设置播放。
- 不开放悬停意图（0.20/0.40 秒）与离开延迟（0.12 秒）。

## 6. 交互与文案

- 分区标题固定为：岛体页「岛体外观」「岛上显示」「功能页面」；行为页「位置」「展开与收起」「避让」；提醒页「提醒方式」「系统状态」「即时通讯」「AI 会话消息」「外部消息」；AI 会话页「接入 AI 工具」「显示」「提醒事件」「提示音」。
- 「通用」页的「高级」是与「启动」同级的标签，其下卡片直接展示，不使用折叠控件。
- 新增设置行文案固定为「动画速度」「展开后停留」「横幅停留」；「展开后停留」的说明写明同时作用于功能页和未读胶囊。
- 「动画速度」用三段选择（慢/标准/快）；两个时长用 −/+ 步进，步进 0.5 秒，范围 1–15 秒。
- 使用「系统状态」而不是「系统消息」：音量、电源、网络、键盘、蓝牙不是消息。
- 使用「提醒事件」「展开提醒」「横幅提醒」「用户选择」「审批」「闲置」等 Hook 语义命名，不用「可能中断」这类含糊说法。
- 「提示音」不设总开关：按事件选择，关闭的事件不会播放声音。
- 迁移时保留现有控件文案和说明，降低学习成本。
- 三个新设置都沿用现有设置的保存时机，不新增「应用」按钮。
- 「自动避让」关闭时，「常用浏览器」和「自定义应用」仍按原逻辑置灰。
- 提醒页只管理提醒策略，不承载音乐、邮件、AI 额度等功能模块的领域设置。

## 11. 风险与已确认决策

### 风险

- **侧栏高度**：16 项在最小高度 450 时行高被压缩，需要测试确认「关于」仍可见（已通过自动化测试）。
- **命名混淆**：「岛体」「行为」「提醒」都可能被误解，通过页面顶部说明与分区标题明确边界。
- **旧入口习惯**：用户可能仍去「外观」「位置」「页面管理」找设置；序号别名保证跳转不失效，但侧栏不再有旧入口。
- **配置兼容**：`interrupted` 与提示音总开关需要兼容旧配置，避免升级后突然开始提醒或发声。
- **提醒页范围膨胀**：容易继续塞入健康、邮件、日程提醒；需要守住「只做提醒策略」的边界。
- **AI 设置分裂**：事件与提示音在 AI 会话页，自动展开与重复提醒在提醒页，需要交叉提示。
- **弹簧调参**：快档可能过冲；只提供三档预设，不开放自由数值。
- **时长范围**：1–15 秒以外的值会被钳制，后续按反馈调整。

### 已确认

- 外观并入岛体，沿用「岛体外观」分组；外观不再单独成页。
- 功能页面并入岛体。
- 位置更名为行为，展开与收起、避让归入行为。
